# Novus UI 设计语言规范 V1.0（Novus Fluent）

> 状态：随 M10 生效
> 适用范围：桌面壳层 `graphics/nd_demo.c`、窗口管理器 `wm/novus-wm/nwm.c`、
> 内置应用 `apps/src/`、图形安装向导 `apps/src/bin/setup.rs`

## 1. 定位

Novus Fluent 是在 Windows 11 Fluent 语言上的收敛，而不是另起一套视觉：

- **三层次 + 一条强调色**：Mica 渐变画布、表面、卡片；强调色只用于可操作元素与当前选中态。
- **1 px 低对比描边**建立边界；阴影只由窗口管理器施加，客户端不模拟阴影。
- **克制的留白**：8 px 网格，内容区至少 16 px 内边距，卡片间距 12 px。
- **两套解析、一套令牌**：浅色与深色是同一组语义色的两种取值，不是两套代码。

## 2. 令牌单一来源

```
tools/themegen/theme.toml          语义色、圆角、间距、控件高度
        │  python3 tools/themegen/themegen.py
        ├── graphics/nd_theme.h    生成：nd_tokens_t / nd_theme_mode_t
        ├── graphics/nd_theme.c    生成：浅色、深色两张表与解析
        └── apps/src/theme.rs      生成：Palette / LIGHT / DARK
```

- 生成物提交仓库，普通构建不需要 Python；改色只改 `theme.toml`，然后 `make theme`。
- `nd_theme.h` 是 C 侧唯一颜色来源；`apps/src/theme.rs` 是 Rust 侧唯一来源。
- 组件与页面禁止出现字面颜色，只能取角色：`ui::text()`、`ui::card_bg()`、`nd_theme_accent()` 等。

### 2.1 语义角色

| 角色 | 浅色 | 深色 | 用途 |
|------|------|------|------|
| canvas_top / canvas_bottom | `#EEF2F8` / `#E3EAF3` | `#1A1E24` / `#11151A` | 桌面 Mica 渐变 |
| surface | `#FFFFFF` | `#202020` | 窗口客户区、对话框底 |
| card | `#FBFBFD` | `#272727` | 卡片、列表底、侧栏 |
| subtle | `#F0F2F5` | `#2E2E2E` | 悬停、弱分区 |
| stroke | `#E1E5EA` | `#3A3A3A` | 1 px 描边、分隔线 |
| text | `#1B1B1B` | `#F5F5F5` | 正文、标题 |
| dim | `#5F6368` | `#B8BCC2` | 次要说明、页脚 |
| accent | `#0067C0` | `#4CC2FF` | 主按钮、选中条、焦点环 |
| on_accent | `#FFFFFF` | `#00243D` | 强调色上的文字 |
| success | `#107C10` | `#6CCB5F` | 完成、校验通过 |
| warn | `#B45309` | `#FCE100` | 需要注意但非破坏性 |
| danger | `#C42B1C` | `#FF99A4` | 破坏性操作、失败 |
| selection | `#E5F1FB` | `#1F3A4D` | 选中行、选中导航项 |

自定义强调色时，`on_accent` 由亮度决定（`luma >= 150` 用深色墨，否则白色），
不依赖预设表。

## 3. 排版

- 字形：ASCII 5×7 点阵，放大 2 倍 = 12 px 步进、14 px 行高；汉字 16×16 点阵。
- 两档字号：`scale 1`（正文，14 px 行高）与 `scale 2`（页面标题，28–32 px 行高）。
- 混排按单元格底边对齐：整行高度取较高单元格。**页面大标题只用一种字形**，
  避免 ASCII 下沉造成的视觉错位；需要混排时拆成标题 + 副标题两行。
- 文本宽度必须查 `nd_text_width()` / `ui::width()`，不得假设"字节数 × 6"。
- 新增中文文案后运行 `python3 tools/fontgen/fontgen.py`，否则缺字显示空心方框。

## 4. 网格、圆角与层级

| 令牌 | 值 | 说明 |
|------|----|------|
| space_xs / s / m / l / xl | 4 / 8 / 12 / 16 / 24 | 8 px 网格 |
| radius_control | 6 | 按钮、输入框、色块 |
| radius_card | 10 | 卡片、浮层、窗口 |
| radius_pill | 18 | 胶囊、任务栏、步骤圆点（取半高） |
| control_h / button_h | 32 / 36 | 控件 / 主按钮高度 |
| row_h | 28 | 列表行（内容区实际绘制 26 + 2 间距） |
| title_h | 32 | 窗口标题栏 |
| shadow_spread | 14 | 仅 WM 使用 |

层级只靠"画布 → 表面 → 卡片"三档明度与 1 px 描边建立；深色模式表面与卡片至少
相差一档明度（`#202020` → `#272727`）。

## 5. 组件规范

### 5.1 按钮

| 类型 | 填充 | 文字 | 用途 |
|------|------|------|------|
| primary | accent（6 px 圆角） | on_accent，居中 | 页面主操作，一屏最多一个 |
| secondary / ghost | card + stroke | text，居中 | 返回、取消、次要操作 |
| danger | card + danger 描边 | danger | 仅确认页/结束任务 |

按下态填充 `subtle`，悬停态加 1 px 强调色内环；禁用态用 `line` 填充 + `dim` 文字。

### 5.2 卡片

`ui::card(x, y, w, h)` = 10 px 圆角填充 `card_bg()` + 同半径 1 px `line()` 描边。
卡片标题 14 px（scale 1）用 `text()`，正文用 `dim()`；卡片之间间距 12 px。

### 5.3 列表行

高 26 px、5 px 圆角；选中行填充 `selection` 并在左侧画 3×16 的强调条；行内左侧
标签、右侧数值；悬停只换 `subtle`，不改变文字色。

### 5.4 导航栏

宽 168–200 px，底色 `card_bg()`，右侧 1 px 分隔线；选中项 = `row_sel` 圆角块 +
3 px 强调条 + `text()`；未选中 `dim()`。

### 5.5 进度、步骤与空态

- 进度条：8 px 高、4 px 圆角，轨道 `line()`，进度 `accent()`，右侧百分比用 `dim()`。
- 步骤：18–22 px 圆点；已完成 = 强调色圆 + 两段短线拼出的对勾；当前 = 强调色圆 +
  序号；未来 = 1 px 描边 + `dim()`。
- 空态：8 px 圆点 + 一行 `dim()` 说明，不放大图标、不使用插图。

## 6. 图标语言

- 24×24 画布内用 3–5 个矩形/线/圆拼出单色字形；颜色取当前文字角色。
- 不使用位图、不引入图片协议；深浅色自动适配。
- 同一含义在全系统只用一个图形（例如"设置"= 圆 + 三横线）。

## 7. 桌面壳层布局

| 区域 | 规格 |
|------|------|
| 桌面 | 画布 Mica 渐变；左下 `Novus OS / Novus Fluent` 水印；右侧竖排磁贴（96×88，间距 8） |
| 任务栏 | 底部居中 660×56 悬浮胶囊，圆角 18；开始/搜索/固定应用/运行指示/时钟/快捷设置 |
| 开始菜单 | 480×560 浮层卡片，`NG_WF_OVERLAY`；搜索框、已固定网格、推荐、用户与电源页脚 |
| 快捷设置 | 340×330 浮层：主题三段、强调色 2×4、壁纸三选、网络状态、电源 |
| 窗口 | 标题栏 32 px、10 px 圆角、14 px 柔影、右侧 `— □ ✕` |

运行中应用指示使用 `apps_count()` + `sched_find_name()` 判断，下方 3 px 强调条。

## 8. 应用页面骨架

```
page()  标题 2x + 副标题 dim + 44×3 强调条 + 分隔线        （内容从 y=78 起）
  card()  10 px 圆角卡片
    section() / row() / kv() / meter()
  footer  次按钮在左、主按钮在右，按钮高 36，提示文字在按钮上方 22 px
```

- 设置：左导航 + 卡片流；个性化页包含"主题"三段选择、"颜色"色板、"桌面背景"预览。
- 文件管理器：34 px 紧凑头部 + 列表行；空目录用空态行。
- 任务管理器：概览卡 + 进程表；状态色 success/warn/dim。
- 网络：状态卡 + 设备行 + 连通性测试，失败用 `warn()` 文字，不弹窗。
- 登录：34 px 头部"本地账户"、两个输入框、主次按钮，标题栏由 WM 提供。

## 9. 主题切换机制

- 模式：`ND_THEME_LIGHT` / `ND_THEME_DARK` / `ND_THEME_AUTO`（默认 AUTO）。
- AUTO 由 `nd_theme_resolve()` 读取 RTC：**19:00–07:00 深色**，其余浅色；无 RTC 时保持上次结果。
- 变更路径：设置页/快捷设置 → `SYSINFO_REQ_THEME`（id=2）→ `nwm_theme_set_mode()`
  → `nd_theme_set_mode()` → `ng_theme_apply()` → 版本号 +1。
- 壳层在空闲 tick 比较 `nd_theme_version()`，变化时重建控件树并整屏重绘；
  窗口管理器标题栏每次绘制读取当前主题。
- Rust 应用启动时 `ui::init(sys_port)`，之后约每秒 `ui::poll()`；版本变化才重绘。
- 协议只做**尾部追加**：`sysinfo_theme_rsp_t` 增加 `mode / resolved / version`，
  不影响旧客户端读取 `accent / wallpaper`。

## 10. 绘制预算与性能

窗口内容是一份显示列表：每窗最多 **120 个 shape、160 段文本**，每段文本 ≤96 字节，
最多 10 个窗口。页面按"每屏 ≤36 shape、32 段文本"设计：

- 卡片 = 1 填充 + 1 描边，不用四条线模拟边框；
- 分隔线复用 1 px 填充，不叠加阴影；
- 客户端 `apps/src/wm.rs` 统计每帧数量，超限只在 COM1 打印一次告警，避免静默截断；
- 进度页每 6 步重绘一次，阶段切换必绘，避免每 128 KiB 刷一帧。

## 11. 交互与可访问性

- 悬停 80 ms 过渡到 `subtle`；按下内缩 1 px；焦点环 2 px `accent` 内嵌，圆角跟随控件。
- 键盘：`Enter` 触发主操作、`Esc` 返回上一步、`↑/↓` 选择磁盘、`Space` 勾选确认。
- 正文与背景对比度目标 ≥4.5:1；强调色不用于小字号正文。
- 最低分辨率 1024×768；安装向导 900×600 居中，1280×800 下上下留白对称。

## 12. 验收清单

1. 浅色、深色、跟随时间三种模式切换后，壳层、窗口标题栏、全部内置应用同时变化；
2. 任意页面无字面颜色、无缺字空心方框（`fontgen` 已重跑）；
3. 开始菜单、快捷设置、安装向导的卡片圆角与描边一致；
4. `[APP] display list over ... budget` 不出现在常规操作日志中；
5. 1024×768 与 1280×800 下无控件越界或被裁切。
