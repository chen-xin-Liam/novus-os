# 中断体系与前台时间片

## 初始化与硬件范围

`CONFIG_NOVUS_IRQ=y` 依赖调度器。`kmain()` 在 `sched_init()` 安装 GDT/TSS/IDT
之后、设备初始化和首次进入 ring 3 之前调用 `irq_init()`，最后开启 COM1 IRQ。
初始化时 IF 保持关闭，所有 IOAPIC 引脚先屏蔽；只有注册成功的设备线路才解除屏蔽。
8259 主从 PIC 的 IMR 均写 `0xff`，LAPIC LINT0 的 ExtINT 输入也被屏蔽。

当前调度与设备 IRQ 都运行在 BSP；AP 完成启动后以 `cli; hlt` 停驻。
IOAPIC 目标取当前 LAPIC ID，不假定 BSP ID 为零。本实现不是多 CPU 并发 ISR 框架。

内核现有引导参数没有传递 RSDP，因此不改引导协议：先扫描内存图中的 ACPI
Reclaim/NVS 区域，再扫描 BIOS EBDA 前 1 KiB 和 `0xe0000..0xfffff`。
验证 RSDP、XSDT/RSDT、MADT 的长度和校验和，解析 MADT 的 IOAPIC 及 ISA
Interrupt Source Override，包括 GSI 基址、低有效极性和电平触发。
只访问当前 identity map 覆盖的低 4 GiB 表；单个扫描区域最多 16 MiB。

无有效 MADT 时会打印明确的 `QEMU fallback` 警告，使用 **QEMU 标准布局**：
IOAPIC MMIO `0xfec00000`、GSI base 0、ISA IRQ 与 GSI 相同；引脚数仍从
IOAPIC version 寄存器读取。这不是适用于任意实机的硬件发现替代方案。

## IRQ 与向量

| 来源 | IRQ / GSI | IDT vector | 触发方式 |
| --- | --- | --- | --- |
| CPU 异常 | 不适用 | 0..31 | 原异常入口不变 |
| LAPIC 定时器 | 本地 | 32 | 原调度入口不变 |
| COM1 | IRQ4 | 动态，默认 33 | 高有效、边沿 |
| PS/2 键盘 | IRQ1 | 动态，默认 34 | 高有效、边沿 |
| PS/2 鼠标 | IRQ12 | 动态，默认 35 | 高有效、边沿 |
| E1000 INTx | PCI 配置 `0x3c` 的 IRQ line | 动态，默认 36 | 低有效、电平 |
| LAPIC spurious | 本地 | 255 | 无 EOI |

设备向量从 33 顺序分配到 254；表中默认值是本配置的注册顺序，不是驱动常量。
MADT 的 ISA override 优先于默认极性、触发方式和 GSI。每个 GSI 最多 4 个
处理函数，共享线路必须使用相同触发属性。注销最后一个处理函数会屏蔽引脚。
向量不会在注销后复用，以免迟到中断调用到其他设备。

接口位于 `kernel/irq.h`：

```c
int vector = irq_register(line, IRQ_LOW | IRQ_LEVEL, device_isr, device, "device");
irq_info_t info;
int status = irq_query(line, &info);
int removed = irq_unregister(line, device_isr, device);
```

`line < 16` 按 legacy IRQ 经 MADT ISA override 转换；其他值直接按 GSI 处理。
`irq_query()` 返回向量、GSI、处理函数数、触发属性、到达计数和无处理函数计数。
注册失败返回负值。计数及查询是内核接口，不新增用户态 syscall 或 IPC ABI。

## 入口、EOI 与并发约定

设备入口使用 DPL0 interrupt gate，CPU 自动清 IF。独立 `irq_common` 保存所有
通用寄存器及 FXSAVE 状态，清 DF，为 MS x64 ABI 对齐栈并留出 shadow space。
设备 IRQ 不调用调度切换，而是原样恢复被打断的 frame。异常、定时器和 syscall
仍使用原路径，未在本任务中重做全局 FPU 任务切换。

所有共享处理函数执行完成后，`irq_dispatch()` **恰好写一次 LAPIC EOI**。
驱动只确认自己的设备状态，不发 LAPIC/PIC EOI。电平设备必须先清除设备中断源，
再由框架 EOI。vector 255 不代表正在服务的硬件中断，不能写 EOI。
注销后的迟到中断会被计数、屏蔽并 EOI。

ISR 不允许 `sti`、睡眠、调度、分配内存、调用协议栈或打印日志。
`irq_save()` / `irq_restore()` 仅在原 IF=1 时重新开启中断，不会意外在已有 ISR
或 syscall 中开中断。IOAPIC 的 selector/window 成对访问也在关中断区间。
当前单 BSP 条件下，队列消费者在很短的关中断区间更新读指针，不需要自旋等待 ISR。

## 驱动队列

- 8042：初始化期间同步交换配置与鼠标命令，注册 IRQ1/12 后将命令字节的 IRQ
  使能位置 1。ISR 最多读 64 字节，记录 AUX 来源到 256 项原始队列；溢出或
  parity/timeout 错误会丢弃字节。原 `nd_input_poll()` 只解码该内存队列，
  **不再读取 0x60/0x64**；事件结构、WM 和文本编辑调用点不变。
- COM1：IRQ4 读取 IIR/LSR，接收字节进入 1024 项队列，`serial_getc()` 非阻塞
  取字节；TX 使用发送空中断，排空后关闭 THRE 中断。`serial_putc/puts()` 接口
  不变。早期启动、关中断日志及发送队列已满时，先同步排空队列再写当前字节，
  避免等待无法运行的自身中断；这是有意保留的紧急日志忙等路径。
- E1000：从 PCI 配置读取 INTx line，清 PCI Command 的 interrupt-disable 位，
  开启 RX、溢出和链路中断。ISR 读 ICR 清源，最多处理 64 个 RX 描述符，将完整
  无错误帧复制到 64 项软件队列并归还描述符；队满则计数丢包。`netdev.poll()`
  仅取软件队列，协议处理及 DHCP/ARP/ICMP/TCP 定时器仍在 `net_tick()` 中执行。
  TX 检查描述符是否空闲。MSI/MSI-X 不在本次实现范围内。

关闭 IRQ 配置不会恢复隐式硬件轮询：PS/2 报告输入不可用，COM1 保留同步输出，
E1000 无可用路由时拒绝注册。未转换的 igb/WiFi 驱动不属于本次三个设备范围。
PCI 固件必须提供可用的传统 IRQ line；本实现不执行 ACPI AML `_PRT`。

## 给新设备添加中断

1. 屏蔽设备自身中断源，准备所有静态缓冲区和硬件状态。
2. 用 IRQ line/GSI 注册处理函数；边沿 ISA 用 flags 0，PCI INTx 通常用
   `IRQ_LOW | IRQ_LEVEL`。检查返回值，失败时不能开启设备中断。
3. 清除设备待处理中断，再打开设备自身中断使能。
4. ISR 先判断是否是自己的中断，只执行有界读取/确认并入队；上层从队列消费。
5. 卸载时先屏蔽设备并停止 DMA，再注销处理函数，最后释放缓冲区。
   框架会屏蔽无处理函数的线路，且不将它的向量分配给别的 GSI。

## 前台时间片

WM 已在内核内执行，因此 `focus_set()` 直接调用 `sched_set_foreground()`，
**没有新增 syscall 或 NWM 消息**。唯一焦点 owner 的基础时间片为 8 ticks，
其他任务为 4 ticks；切换 owner 后旧任务恢复 4、新任务从 8 开始。
同一 owner 的不同窗口之间切换不补充剩余额度，重复聚焦也不补充。
最小化、关闭、owner 退出、回到 shell 都清除对应前台权重；kernel shell 没有
独立用户进程，使用 `SCHED_FOREGROUND_NONE`，不把 pid 0 的 idle 误认为 shell。
聚焦已最小化窗口会恢复窗口。yield/exit 和原轮转顺序不变，恢复运行时按权重补片。

任务管理器通过原有 `slice` 字段显示**剩余**时间片；大于 4 时使用强调色。
这不是固定前后台标签：前台任务已消耗到 4 以下，或主动 yield 后，也会显示小值。
现有 syscall 编号、协议结构及字段语义均不变。

启动自检验证 4/8、重复聚焦不补片、无效 PID 不改状态、切换和 shell 清除，
并让两个持续就绪任务模拟 120 ticks，断言前台 80、后台 40。
WM 自检另经真实 focus/minimize 请求验证 owner 迁移。这证明分配比例，
不声称主动阻塞或 yield 的交互应用在实测中必然获得两倍 CPU。

## 双引导兼容修复

原始 HEAD 的 BIOS 镜像也在 Merkle 自检中三重故障，发生于 IRQ 初始化前；
在取得额外修复许可后处理了两处阻塞：

- BIOS 内核 C 默认 MS ABI，而裸机 Rust 编译器生成的内存原语调用是 SysV ABI。
  `kernel.h` 和内存原语定义仅在 BIOS 下显式使用 `sysv_abi`；UEFI 不变。
- 独立 AP 跳板不能携带未解析 ELF 重定位；远跳转改为节内常量，地址槽用本地
  别名。进入 C 之前设置 SSE 支持并留出 MS ABI shadow space。参数槽尾部按
  16 字节边界布局，确保 COFF 提取裸二进制的填充不破坏“最后 24 字节”约定。

基线故障日志与异常跟踪保留在 `out/irq-bios-pc-baseline*`。
