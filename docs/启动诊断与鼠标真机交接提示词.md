## 已完成、别再重做

**鼠标（QEMU 已验证，真机未验证）** `kernel/usb.c`：
- `USB_MAX_PORTS` 8→32（Intel PCH 常上报 16–24 口，第 9 口起此前永不 reset）；
- `port_reset` 加 PPC/PP 上电（HCCPARAMS1 bit3 且 PORTSC bit9=0 时置 PP、等真置位、空转约 20 ms）；
- `xhci_cap_sane()` 校验 CAPLENGTH/HCSPARAMS1/HCCPARAMS1（**故意不校验 HCIVERSION**，QEMU 读出 0），插在 `relocate_bar0` 候选筛选里，`usb_init` 里再加一次重定位兜底；
- class 9 显式认成 `USB_KIND_HUB`，打印后释放；
- 新增 `kernel/i2c_hid.c`（I2C-HID over DesignWare，供 HP 触控板）。QEMU 无此设备，只验到总线枚举层，**真机表现未知**。
QEMU 证据：`[USB] BAR0 moved to 0xF0000000`、`xhci 0:3.0 ports=8`、`HID addr=0x1 port=0x5 kind=mouse`、`addr=0x2 port=0x6 kind=keyboard`、两条 `HID interface ready`；monitor `mouse_move` 注入后截图光标位移（`/tmp/n58.png` → `/tmp/n58b.png`）。

**开机动画 4.3 s 冻结**：真因是 boot 阶段第一次 `novus_timeline` 触发 TSC 频率探测，而 ACPI FADT 的 PM 定时器端口尚未设（`g_pm_timer_port=0`），三个候选端口各空转 20,000,000 次 `io_in32`。修法：`kernel/kmain.c` 加 `novus_timeline_seed(start_tsc,hz)` / `novus_timeline_reset()`；`arch/x86_64/boot/main.c` 加 `boot_timeline_publish()`，在 `boot_timeline("splash capture print done")` 后、`nd_boot_clock_set` 前调用；`kmain()` 在 `acpi_pm_timer_port(...)` 后 reset。现在 `[CAP] capture total 2ms`，`[BA] frame 1/7…7/7` 落在 0/122/241/361/481/601/721 ms。

**主板 / OEM logo**：`graphics/nd_oemlogo.c` 加了完整 ACPI BGRT 解析（EFI 配置表→RSDP→XSDT/RSDT 找 `BGRT`，校验 status bit0 与 image_type==0，BMP 24/32bpp、负高度 top-down、四角均值做 alpha 键），等比缩到 `448×176`。QEMU：`[ND] logo: ACPI BGRT bitmap 193x58 key=0xB5B8C7`、`[BOOT] firmware boot logo captured`。

**网络全链**：QEMU 挂 e1000 的唯一可行写法是自造 512 B 假 option ROM（`/tmp/pxe-e1000.bin`，0x55AA+PCIR），命令行 `-netdev user,id=n0 -device e1000,netdev=n0,addr=0x7,romfile=/tmp/pxe-e1000.bin`——**`addr=0x7` 是关键**，否则 PCI 拓扑变化会让 `vars*.fd` 里 `Boot0002 PciRoot(0x0)/Pci(0x4,0x0)` 失效、OVMF 掉进 UEFI Shell。权威日志 `/tmp/sx62.log`：`[NET] e1000 up` → `dhcp discover/offer` → `ip 10.0.0.2 gw 10.0.2.2` → `arp` 双向 → `ping rtt=10ms` → `[DNS] answer 154.36.184.64` / `203.107.6.88` → `tcp connect→established→rx 0xB2→closed` → `[NCSI] connected {"online":true}` → `[NTP] synced via ntp.aliyun.com, offset 0s`。已回填总表 7-9、18-4 为 ✅。已撤除的 NETPROBE 引导期 TCP 探针（`net_tcp_probe_boot()` 等）**全部删干净了，别再复活**。

## 复现 QEMU 的最小步骤（vm 环境）

```bash
export LD_LIBRARY_PATH=/home/user/local/lib/x86_64-linux-gnu:/home/user/local/usr/lib/x86_64-linux-gnu
export QEMU_MODULE_DIR=/home/user/local/usr/lib/x86_64-linux-gnu/qemu
curl -sSL -o /tmp/desk.img https://aka.doubaocdn.com/s/ihUh2VET8U
cp /tmp/vars59.fd /tmp/varsNN.fd          # 必须复用这个 vars，内含可用 Boot 项
/home/user/local/usr/bin/qemu-system-x86_64 -m 3072 -smp 2 -L /home/user/local/usr/share/qemu \
 -drive if=pflash,format=raw,readonly=on,file=/home/user/local/usr/share/OVMF/OVMF_CODE.fd \
 -drive if=pflash,format=raw,file=/tmp/varsNN.fd \
 -drive file=/tmp/desk.img,format=raw,if=virtio \
 -netdev user,id=n0 -device e1000,netdev=n0,addr=0x7,romfile=/tmp/pxe-e1000.bin \
 -device qemu-xhci -device usb-mouse -device usb-kbd -vnc 127.0.0.1:8N \
 -monitor unix:/tmp/monNN,server,nowait -serial file:/tmp/sxNN.log -display none
```
