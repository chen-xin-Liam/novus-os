## 产品概述

让 Novus OS 的桌面支持中文，并重做成 Windows 11 风格：圆角窗口、居中悬浮任务栏、悬浮圆角开始菜单、浅色云母背景；界面文案全部中文，文本框可用拼音输入中文。

## 核心功能

- **中文显示**：UTF-8 文本端到端（外壳、窗口标题、按钮、列表、状态栏、三个系统应用），汉字用 12x12 内嵌点阵，与 ASCII 5x7 放大 2 倍混排对齐。
- **中文输入**：聚焦文本框后键入拼音字母，弹出候选窗显示候选汉字，空格/数字键/回车选字上屏，Esc 取消、退格改拼音，候选写入光标处（UTF-8 多字节编辑）。
- **Win11 桌面**：浅色云母渐变桌面 + 桌面图标（文件管理器/任务管理器/设置/关于），底部居中悬浮任务栏（开始按钮 + 应用按钮 + 时钟），点击开始弹出悬浮圆角菜单列出全部应用。
- **Win11 窗口**：10px 圆角、柔和投影、32px 标题栏（左标题、右 — □ ✕ 三键，关闭键悬停变红）、浅色控件（白底、浅灰悬停、蓝色焦点环）。
- **演示窗口收纳**：原 NovusDisplay 控件演示与 Widgets 窗口不再开机自动显示，改为开始菜单/桌面"关于演示"入口打开。
- **时钟**：任务栏显示真实时间（新增 CMOS RTC 读取，每秒刷新）。

## 视觉与交互

深色主题整体改为浅色：桌面为淡蓝灰云母渐变，窗口纯白、标题栏浅灰、正文近黑，强调色 Windows 蓝；所有可点元素有悬停/按下反馈，窗口与开始菜单带圆角与投影，任务栏悬停有浅色胶囊高亮。

## 技术栈

沿用现有 C 内核 + Rust 用户态：`graphics/`（NovusDisplay 2D 与 nvgui）、`wm/novus-wm/`、`apps/`（Rust，x86_64-unknown-none）。新增两套离线代码生成器（宿主机 Python + PIL），产物为 **提交进仓库的 C 源码**，构建不依赖宿主字体。

## 现状与改造点（已核对代码）

- `graphics/nd_font.c`：仅 5x7 ASCII（95 字形、7 字节/字形、`bit4` 最左列），`ND_FONT_ADV=6`、`ND_FONT_LINE=9`。
- `graphics/nd_core.c`：`nd_text_limit()` 逐字节推进，`nd_text_width()` 按字节数×步进。
- `graphics/nvgui.c`：`draw_edit()`（约 535-590 行）与 `textbox_key()`（约 937-1000 行）把"字节=字符=6px"写死，只接受 `0x20..0x7E`；`theme_init()` 为深色；`draw_window()` 圆角 8px、标题 30px。
- `wm/novus-wm/nwm.c`：`paint_window()` 标题栏 24px、12x12 三键、圆角 6px、标题 `nd_text(...,1)`；`nwm_text_t.text[96]` 按字节，损伤宽度 `len*6`。
- `graphics/nd_demo.c`：`build_desktop()` 顶部 34px 任务栏 + 三个按钮，两个演示窗口固定位置且开机显示，底部状态栏文本。
- `apps/src/ui.rs`：`Buf::col(n)` 与列宽按 6px/列；三个 bin 文案为英文。
- 无 RTC 驱动，任务栏时钟需新增 CMOS 读取。

## 实现方案

### 1. 文本管道（UTF-8 + 汉字点阵）

- 新增 `graphics/nd_font_cjk.c`（生成产物）：按码点升序的字形索引表 + 12x12 点阵（2 字节/行 × 12 行）。
- `nd.h` 增加：`nd_char_adv(cp, scale)`、`nd_text_height(text, scale)`、`nd_text_advance(text, n_codepoints, scale)`、`nd_utf8_next(const char **)`。
- `nd_core.c`：`nd_text_limit` 改为解码 UTF-8，ASCII 走原 5x7 表（scale 内插），汉字走 CJK 表；统一基线（单元格 14px，汉字垂直居中 1px），缺字回退 `□`。
- 所有假设"6px/字节"的地方改为查度量：`nvgui` 文本框光标/滚动/`max_chars`、`nwm.c` 文本损伤矩形、`nd_demo` 布局、`apps/src/ui.rs` 的 `col()`/宽度（Rust 侧实现 `adv(cp)`，CJK=12、ASCII=6，`col_px(px)` 以空格补齐）。

### 2. 离线生成器（产物入库）

- `tools/fontgen/fontgen.py` + `tools/fontgen/charset.txt`：读 Noto Sans CJK（`.ttc`）渲染 12x12 1bpp，输出 `graphics/nd_font_cjk.c`（含码点表、位图、`ND_CJK_COUNT`）。
- `tools/imegen/imegen.py` + `tools/imegen/pinyin.txt`：从拼音表抽取"音节 → 至多 6 个常用字"，输出 `graphics/nd_ime_dict.c`（音节字符串池 + 候选表 + 二分查找）。
- Makefile 提供 `make glyphs`/`make ime`（需宿主机字体，开发期用），默认构建只用已提交的 C 文件。
- `charset.txt` 由脚本从所有 UI 字符串 + 字典用字去重生成，保证字形集合与文案同步。

### 3. 拼音输入法（`graphics/nd_ime.c/h`）

- 状态机：idle / composing；`pinyin[16]`、候选 `[6]`、高亮索引。
- 接管按键（`ng_dispatch` 在 `textbox_key` 之前调用）：`a-z` 累积、退格删字母、空格/回车/1-6 上屏、左右选候选、Esc 清空。
- 候选窗：浮层绘制在光标下方，圆角浅色面板（拼音 + 候选 + 序号），超出屏幕自动上翻；遮住区域并入损伤区。
- 上屏：把 UTF-8 字节插入 `edit.buf` 光标处，`len` 按字节、光标移动按码点边界；`textbox_key` 的插入/退格改为按码点。
- 仅作用于 nvgui 文本框（外壳），M8 应用无文本输入，不做 IME 入应用。

### 4. Win11 主题与窗口装饰

- `theme_init()` 换浅色：桌面 `#EEF2F8→#E3EAF3`，窗口 `#FFFFFF`，标题 `#F3F3F3`，正文 `#1B1B1B`，次要 `#5F6368`，强调 `#0067C0`，控件 `#FBFBFB`，悬停 `#F0F0F0`，边框 `#E1E5EA`。
- `draw_window()`/`paint_window()`：圆角 10px、阴影 spread 14/alpha 48、标题栏 32px、三键 46x32 命中区（悬停浅灰、关闭悬停 `#C42B1C` 白色 ✕），标题 12px 中文，客户区裁剪不变。
- 控件：按钮/文本框/列表圆角 4-6px，焦点环 2px 强调色，列表选中 `#E5F1FB`。

### 5. Win11 外壳（`nd_demo.c`）

- 桌面：`nd_gradient_v` 双层 + 顶部高光椭圆混合（云母感）。
- 桌面图标：4 个圆角磁贴（120x96），单击选中、双击/回车打开（三个应用走 `apps_launch`，"关于/演示"显示 M5 两个窗口）。
- 任务栏：底部居中悬浮胶囊（约 560x48、圆角 12、`#F9F9F9` 90% 叠加），左开始按钮（四格窗格图形），中间应用按钮（图标 + 中文名，悬停胶囊高亮，运行中下方小圆点），右时钟 `HH:MM`。
- 开始菜单：点击开始时在任务栏上方弹出（360x430、圆角 12、投影），含"已固定"网格（4 个应用磁贴）与"推荐/关于"列表行；点击外部或再次点开始关闭。
- 演示窗口改为 `ng_show(w,0)` 初始隐藏，由开始菜单/桌面图标打开；状态行改为浅灰小字。

### 6. RTC 时钟（`kernel/rtc.c/h`）

- CMOS 0x70/0x71 读秒/分/时，处理 BCD 与 update-in-progress 位；`rtc_now(&h,&m)`；tick 每秒缓存一次，`nd_demo` 读取；无 RTC 时回退显示 uptime 分钟数。

### 7. 全量中文化

- 外壳：任务栏/开始菜单/桌面图标/窗口标题/状态提示。
- WM 默认标题与按钮提示、`nd_demo` 两个演示窗口内容（标签、按钮、列表项、树节点）、状态栏。
- 三个 Rust 应用：窗口标题（文件管理器/任务管理器/设置）、表头、行标签、状态文案、按钮（运行/刷新/启动中…）、设置项（桌面强调色/运行时间/空闲内存/任务数/窗口数/IPC 收发）。

### 性能与约束

- 汉字点阵约 1000 字 ≈ 24KB、字典 ≈ 20KB，均为只读 `.rodata`；文本绘制只在损伤区内逐像素写，字号不变，单帧成本与现状同量级。
- 文本查字用码点二分（≤10 次比较/字），无额外分配；IME 只在击键时更新，候选窗独立损伤区。
- 兼容性：无 CJK 字形的旧 ASCII 路径不变；`wm-churn.sh` 压力回归、IPC/NWM/ND 自检必须继续通过。

## 设计风格

Windows 11 Fluent：浅色云母（Mica）桌面、白色圆角应用卡、克制的蓝色强调、柔和投影与胶囊悬停反馈。整体信息密度接近 Windows 11 桌面（9pt 正文 ≈ 12px），不使用渐变高光与玻璃模糊，改用"两层浅色 + 柔和阴影"在 1bpp 点阵环境下还原质感。

## 页面与区块规划（三个主屏）

### 1. 桌面（Desktop）

- **顶栏**：无（Windows 11 无顶栏），仅在左上角显示小号"Novus OS"水印文字。
- **桌面图标区**：左上 2×2 网格，120x96 圆角磁贴，图标为 32x32 线框图形 + 12px 中文名；悬停浅蓝底、选中带 2px 蓝框。
- **主视觉**：中央留空，淡蓝灰渐变自左上向右下过渡，右上角一枚极淡的白色径向高光。
- **任务栏**：底部居中悬浮胶囊（560x48，圆角 12，白 92%），从左到右：开始（四格窗格）、分隔线、三个应用图标按钮（图标+中文，运行中底部 4x4 圆点）、右侧时钟 `HH:MM` 与日期；悬停为浅灰胶囊。
- **状态提示**：左下角 12px 浅灰单行状态文本（保留调试价值）。

### 2. 开始菜单（Start）

- **面板**：360x430，圆角 12，白底 + 24px 柔和投影，悬浮于任务栏上方 8px 处，带 150ms 上滑淡入（用两帧位移模拟）。
- **搜索行**：顶部 36px 圆角输入框样式（静态提示"搜索应用"）。
- **已固定网格**：标题"已固定"，4 个 100x88 磁贴（文件管理器/任务管理器/设置/关于），图标 + 中文名，悬停浅灰。
- **推荐列表**：标题"推荐"，3 行列表（最近使用 / 系统信息 / 控件演示），右侧箭头，悬停浅灰。
- **页脚**：分隔线 + 左侧用户胶囊"Novus 用户"，右侧电源样式图标（点击仅关闭菜单）。

### 3. 应用窗口（Win11 窗口）

- **标题栏**：32px，浅灰 `#F3F3F3`，左侧 12px 中文标题，右侧 — □ ✕ 三个 46x32 命中区，悬停浅灰、关闭悬停红底白字。
- **客户区**：纯白、内容留白 12px、控件圆角 4-6px。
- **边框与投影**：1px `#E1E5EA` 边框、10px 圆角、14px 柔化阴影；焦点窗口边框略深。
- **文本框与 IME**：聚焦时 2px 蓝框 + 光标 2px 蓝色；拼音输入时候选窗为 240x104 圆角面板，首行拼音（灰）+ 候选 6 个（16px 网格），高亮候选蓝底白字。

## 交互与动效

- 悬停 80ms 变色的即时反馈；任务栏按钮按下有 1px 内缩；窗口拖动实时跟随；开始菜单开合用两帧位移 + 明暗过渡；候选窗跟随光标、越界自动上翻。
- 键盘：Tab 在窗口内遍历控件，Esc 关开始菜单/取消输入法，Enter 触发默认按钮。

## Agent Extensions

### SubAgent

- **code-explorer**
- Purpose: 在动手前用语义检索把所有"字节数当字符数/6px 当字宽"的调用点列全（`nd_text_width`/`ND_FONT_ADV`/`len*6`/`Buf::col`/`max_chars`/损伤矩形），产出改造清单，避免漏改导致中文错位或裁剪。
- Expected outcome: 一份按文件分组的调用点清单（文件:行号 + 现假设 + 应改为的度量 API），作为文本管道任务的验收对照。
