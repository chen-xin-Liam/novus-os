# 分阶段实现路线图

本轮采用「全功能一次实现」；下列阶段表示实施顺序与依赖关系，均已在本轮交付。

## 阶段 1：骨架与契约

- workspace、Makefile、环境脚本、静态链接与校验脚本
- C 静态库构建、FFI 结构定义与 RAII 封装
- HAL trait、能力位与降级原因契约
- 极简 C 测试框架与空扫描流程
- 状态：完成

## 阶段 2：检测核心

- Aho-Corasick 自动机、跨块重叠窗口
- CRC32 / SHA-256 / FNV / 滚动哈希
- 启发式评分、内容定义分块与模糊指纹
- 特征库加载、wildcard 展开、EICAR 正例验证
- 状态：完成（15 个 C 单测 + 检测集成测试通过）

## 阶段 3：扫描与更新

- 按需扫描、目录树递归、定时扫描、实时事件接入
- 固定容量优先级队列与背压
- 增量包校验、原子替换、版本比较与回滚
- 状态：完成

## 阶段 4：行为与沙盒

- 三层行为事件状态机与拦截决策
- 沙盒策略编码、会话生命周期
- Linux fanotify / procfs / eBPF 与沙盒能力探测，失败自动降级
- 状态：完成（内核级沙盒隔离依赖主机能力，缺失时策略模式）

## 阶段 5：隔离与告警

- 隔离区 stash / restore / delete 与容量控制
- 结构化日志、去重、限流与告警输出
- CLI 管理命令
- 状态：完成

## 阶段 6：验证与迁移

- C + Rust + 集成 + 端到端测试
- 静态链接校验、核心纯度审计
- Novus OS 迁移骨架、syscall/VFS 映射、128 KiB 体积检查
- 状态：完成

## 已知边界

- eBPF 与 seccomp/namespaces 的最终隔离强度取决于运行主机的能力与内核配置；不可用时明确降级。
- Novus OS 暂无文件事件、进程追踪、通用 syscall 探针与内核沙盒钩子；对应能力在 HAL 中标注为缺失，等待 OS 侧接口落地后补后端。
- 变种识别使用固定 32 字节指纹，适合同源粗聚类，不替代完整模糊哈希库。
