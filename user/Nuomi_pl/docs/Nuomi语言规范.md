# Nuomi 语言规范（Language Specification）

> **版本**：0.1（对齐当前树遍历解释器实现）
> **定位**：一门用 C 从零实现的**极简 Lisp 风格**编程语言，最终目标产物为 novus-os 的 `.nuc` 原生可执行文件。
> **权威性**：本文是 Nuomi 语言的**权威规范**。当本规范与《Nuomi 语言手册》等教程性文档冲突时，**以本规范为准**；教程可能滞后于实现。
> **范围**：词法结构、语法、数据类型、求值模型、特殊形式、内置函数、错误语义、表示法、已知限制。

---

## 1. 概述

Nuomi 源码即 **S-表达式（S-expression）**序列。程序由若干**形式（form）**组成，按书写顺序求值；最后一个形式的求值结果即整个程序的退出返回值（供宿主/REPL 使用）。解释器为**树遍历**式：读入源码 → 解析为值树（AST）→ 递归求值。

设计原则：极简、词法直观、一切皆值、闭包 + 词法作用域、无宏/模块/异常（当前版本）。

## 2. 词法结构（Lexical Structure）

### 2.1 空白与注释
- 空白：空格 ` `、水平制表 `\t`、换行 `\n`、回车 `\r` 均作分隔。
- 注释：以 `;` 起，至行尾；语义等同空白。

### 2.2 词法元素与定界符
- **定界符（delimiter）**：`(` `)` `[` `]` `'` `;` 以及空白字符。符号/数字以首个定界符结束。
- **原子（atom）**：数字、布尔、`nil`、字符串、符号。

### 2.3 数字（number）
- 统一为 IEEE-754 **双精度 `double`**，无整数/浮点类型区分。
- 判定规则：一个原子令牌若能被 C `strtod()` **整体消费到底**，即为数字；否则为符号。
  - 例：`42` `3.14` `-0.5` `.5` `1e3` 为数字；`+` `->` `1abc`（`strtod` 停在 `abc`）为符号。

### 2.4 布尔与空值
- `true` / `false` → 布尔值。
- `nil` → 空值。

### 2.5 符号（symbol）
- 不可整体解析为数字的原子即为符号；符号为标识符，用以引用变量/函数。
- 符号按内容**驻留（interned）**：相同文本的符号是同一对象。

### 2.6 字符串（string）

Nuomi 提供**两种**字符串定界符，语义完全相同：

| 定界符 | 写法 | 转义 | 说明 |
|--------|------|------|------|
| **❝ … ❞**（推荐） | `❝hello❞` | **不解析转义** | 独特定界符（U+275D / U+275E）。内容原样保留，双引号/反斜杠无需转义 |
| **" … "**（传统） | `"hello"` | 处理转义 | 向后兼容主流写法 |

- **为什么用 ❝❞ 作首选**：主流语言都用 `"` 或 `'`；而 Lisp 家族里 `'` 得让位给 quote，语义容易打架。Nuomi 把 `' 一心一意留给 quote，`❝❞` 独树一帜——看到就知道是 Nuomi，且`❝` 内嵌 `"` 无需转义，写嵌套文本很省心。
- 传统 `"` 的**转义序列（精确）**：

  | 写法 | 结果 |
  |------|------|
  | `\n` | 换行 U+000A |
  | `\t` | 制表 U+0009 |
  | `\"` | 双引号 `"` |
  | `\\` | 反斜杠 `\` |
  | `\c`（其他任意字符 c） | **反斜杠被丢弃，得到字符 `c` 本身** |

  - ⚠️ 注意：**未实现** `\r`（`\r` 得到字母 `r`）、`\0`、`\xHH` 等。
- 未闭合的字符串为**解析错误**。
- 两种定界符写出的字符串 `equal?` 相等：`(equal? ❝x❞ "x")` → `true`。

### 2.6.1 字符串在编译产物中的内存布局

编译（`nuomi -c`）时，字符串字面量进入只读数据段（RODATA），运行时字符串的值即其首地址。每个字符串采用**自描述头部**布局（按 8 字节对齐）：

```
偏移 0   int64  长度（字节数，不含头部）
偏移 8   int64  内容哈希（FNV-1a 64 位）
偏移 16  char[] 字节数据（非 NUL 结尾）
```

- 相同字面量**自动去重**，编译期只存一份；
- 运行时比较字符串可先比哈希再逐字节。

### 2.7 列表与向量
- 列表：`(form ...)`，用圆括号。
- 向量：`[form ...]`，用方括号。
- 逗号非法但无害——逗号不是定界符，会并入相邻符号文本（不推荐书写逗号）。

### 2.8 引号缩写
- `'x` 是 `(quote x)` 的语法糖：原样返回随后的形式，不求值。可作用于任意形式：`'(1 2 3)`、`'[1 2 3]`、`'(+ 1 2)`。

## 3. 语法（Grammar）

EBNF：

```
program  := form*
form     := atom | quoted | list | vector
atom     := number | 'true' | 'false' | 'nil' | string | symbol
quoted   := "'" form
list     := '(' form* ')'
vector   := '[' form* ']'
string   := '"' ( <非引号字符> | escape )* '"'
escape   := '\\' <任意字符>
symbol   := <任意非数字、非定界符的原子>          ; 见 2.3/2.5
number   := <可被 strtod 整体解析的令牌>
```

## 4. 数据类型与文本表示

### 4.1 值类型
| 类型 | 说明 |
|------|------|
| `nil` | 空值 / 空列表尾 |
| `boolean` | `true` / `false` |
| `number` | 双精度浮点 `double` |
| `symbol` | 驻留的标识符（求值时查环境） |
| `string` | 字符序列 |
| `proper list` | cons 链，尾为 `nil`：`(1 2 3)` |
| `improper list` | cons 链，尾非 `nil`（点对）：`(1 . 2)`、`(1 2 . 3)` |
| `vector` | 可随机访问、可原地修改的数组：`[1 2 3]` |
| `closure` | `lambda`/`define` 函数，含名字、形参、函数体、捕获环境 |
| `native` | 内置函数（C 实现），不可被程序直接构造 |

### 4.2 真值（truthiness）
- **假值只有两个**：`nil`、`false`。
- **其余一切皆为真**——包括 `0`、`0.0`、空字符串 `""`、空列表、空向量。

### 4.3 文本表示（`print` / `println` / 嵌套，实测）
| 值 | 表示 |
|----|------|
| `nil` | `nil` |
| 布尔 | `true` / `false` |
| 整数数值 | 无小数点，如 `42`、`-7` |
| 非整数数值 | `%g`，**默认 6 位有效数字**：`3.14159`、`0.333333`、`1e+20` |
| 字符串 | **带双引号**：`"hello"` |
| proper 列表 | `(a b c)` |
| improper 列表 | `(1 . 2)`、`(1 2 . 3)` |
| 向量 | `[a b c]` |
| 闭包 | `<fn 函数名>`（匿名为 `<fn lambda>`） |
| 原生函数 | `<native 名>`，如 `<native car>` |
- ⚠️ `print`/`println` 顶层及嵌套中的字符串**均带引号**；仅 `str` 拼接产生**不带引号**的裸串（见 §7.12）。

## 5. 求值模型（Evaluation）

设当前环境为 `env`。对形式 `f` 求值 `eval(f, env)`：

1. **数字 / 布尔 / nil**：自求值，原样返回。
2. **字符串字面量**：自求值，返回该字符串。
3. **符号**：在 `env` 及其外围环境中查找绑定；**未绑定 → 运行时错误 `unbound variable`**，该表达式求值为 `nil`。
4. **闭包 / 原生函数对象**：自求值，返回自身。
5. **列表 `(head a1 …)`**：
   - 若 `head` 是**保留特殊形式符号**（§6），按对应特殊形式规则求值。
   - 否则为**函数应用**：先求值 `head` 得被调用者（符号则查环境），再**从左到右**求值各实参，最后 `apply`。
6. **向量 `[e1 …]`**：**非自求值**。逐个求值每个元素，返回一个**新向量**（每次求值向量字面量都产生新对象）。要得到不被求值的数据向量，用引号 `'[1 2 3]`。

`quote`（§6.1）返回其参数的形式对象本身。

## 6. 特殊形式（Special Forms）

> 特殊形式的参数**不**被默认先求值。
> ⚠️ 以下符号为**保留字**：`quote if while define set! lambda begin and or`。当列表首元素是这些名字的符号时，**一律按特殊形式分派**——即便你 `define` 了同名函数，也无法以 `(if …)` 形式调用它。

### 6.1 `quote`
`(quote x)` → 返回 `x` 本身，不求值。等价 `'x`。

### 6.2 `if`
`(if cond then)` 或 `(if cond then else)`：求值 `cond`，按真值（§4.2）选择分支；`else` 省略且条件为假 → 返回 `nil`。

### 6.3 `while`
`(while cond body…)`：循环——求值 `cond`，为真则求值全部 `body…`（在**当前环境**中），重复。返回**最后一次迭代**的最后一个 body 值；若一次都未进入 → `nil`。

### 6.4 `define`
两种形式：
- `(define name expr)`：在当前环境把 `name` 绑定到 `expr` 的求值结果；返回该值。
- `(define (name p1 p2 …) body…)`：等价于 `(define name (lambda (p1 …) body…))`，即创建具名闭包；返回该函数对象。
  - `name` 必须是符号；函数名的形参表首元素需为符号列表。

### 6.5 `set!`
`(set! name expr)`：`name` **必须已存在绑定**（否则 `set!: unbound variable`），将其槽位更新为 `expr` 的求值结果；返回 `nil`。

### 6.6 `lambda`
`(lambda (p1 …) body…)`：创建**匿名闭包**（名为 `<lambda>`），捕获当前环境；形参必须是符号。返回闭包。

### 6.7 `begin`
`(begin f…)`：顺序求值所有形式，返回**最后一个**的值；空 → `nil`。

### 6.8 `and`
`(and a b …)`：从左到右求值，**短路**。遇到首个假值 → 返回该**原值**并停止；若全为真 → 返回最后一个的**原值**；空 → `true`。
- 例：`(and 1 2)`→`2`；`(and 1 false 2)`→`false`；`(and)`→`true`。

### 6.9 `or`
`(or a b …)`：从左到右求值，**短路**。遇到首个真值 → 返回该**原值**并停止；若全为假 → 返回最后一个的**原值**；空 → `nil`。
- 例：`(or nil false 5)`→`5`；`(or nil false)`→`false`；`(or)`→`nil`。

### 6.10 `let`
`(let ((name init) …) body…)`：**局部作用域**。所有 `init` 先在**外层环境**求值，再统一绑定进新建的子环境，然后顺序求值 `body…`（返回最后一个值）。
- 绑定列表元素必须是 `(name init)` 二元组；`name` 必须是符号。
- **并行绑定**语义：后一个 `init` **看不到**同一个 `let` 里前面刚绑定的名字。
  - 例：`(define x 10) (let ((a 1) (b x)) (list a b))` → `(1 10)`。
- 空绑定 `()` 合法，等价于只开一层作用域。
- 内部 `lambda` 可捕获 `let` 建立的绑定（闭包），`set!` 可修改它——这是实现带状态闭包的标准写法。

### 6.11 `let*`
`(let* ((name init) …) body…)`：**顺序绑定**的 `let`。每个 `init` 在「前面已绑定的名字可见」的环境中求值，绑完一个再算下一个。
- 例：`(let* ((a 1) (b (+ a 10))) (list a b))` → `(1 11)`。这是 `let` 做不到的（`let` 中`b` 求值时看不到 `a`）。

### 6.12 `letrec`
`(letrec ((name init) …) body…)`：先把全部 `name` 绑定为 `nil`，再依次求值 `init` 并写回同一作用域。因此 `init` 内可**自引用或互相引用**已列出的名字——用于定义互相递归的局部函数。
- 例：
  ```lisp
  (letrec ((even? (lambda (n) (if (= n 0) true  (odd?  (- n 1)))))
           (odd?  (lambda (n) (if (= n 0) false (even? (- n 1))))))
    (even? 10))   ;=> true
  ```
- 语义上等价于「先占位为 nil 再赋值」，故在 `init` 里调用尚未求值完的名字会得到 `nil`（而非错误）。

> 注意：`and`/`or` 返回**操作数原值**而非强转为布尔。

---

### 6.13 实现注记：作用域与栈深度

- **作用域**：环境是链式结构，`let` 系列各自新建一层子环境，出作用域即释放。词法作用域（闭包捕获的是**定义处**的环境，而非调用处）。
- **递归深度**：求值器对每个嵌套表达式消耗一层 C 栈。解释器运行在一个显式加大栈（256MB）的线程上，并把嵌套深度限制在 `NUOMI_MAX_DEPTH = 12000`（约合 **3700+ 层函数递归**）。超过时抛出 `maximum recursion depth exceeded` 并终止本次求值——**给出可读报错，而不是段错误**。

## 7. 内置函数参考（Native Functions）

> 除特别说明，参数求值后才传入；出错时函数向 `stderr` 打印 `Runtime error: <msg>` 并**返回 `nil`**（不中断程序，见 §8）。

### 7.1 算术
| 函数 | 语义 | 备注 |
|------|------|------|
| `(+ …)` | 求和 | 0 参 → `0`；全部参数须为数字 |
| `(- a b …)` | 左结合相减；`(- x)` 单参 → `-x` 取负 | |
| `(* …)` | 求积 | 0 参 → `1` |
| `(/ a b …)` | 左结合相除；`(/ x)` 单参 → `1/x` | 除数为 0 → `division by zero` |
| `(% a b)` | 浮点取模 `fmod` | 恰 2 个数字参数；模 0 → `modulo by zero` |

### 7.2 比较（链式，全部成立才为 `true`）
| 函数 | 语义 |
|------|------|
| `(= …)` | 全等于首元素 |
| `(< …)` | 严格递增 |
| `(> …)` | 严格递减 |
| `(<= …)` | 非递减 |
| `(>= …)` | 非递增 |
- 仅接受数字；**出现非数字 → 返回 `false`**（不报错）。0 或 1 参 → `true`。

### 7.3 逻辑与相等性
| 函数 | 语义 |
|------|------|
| `(not x)` | `x` 为假值 → `true`，否则 `false` |
| `(equal? a b …)` | **结构相等**：列表/向量递归比较元素，字符串逐字符，数值/布尔/空按值；`<2` 参 → `true` |
| `(eq? a b …)` | **同一性**：对象比较指针；`nil`/布尔/数值比值；`<2` 参 → `true` |

### 7.4 输出
| 函数 | 语义 |
|------|------|
| `(print a …)` | 参数以**单个空格**分隔打印，**不换行**；返回 `nil` |
| `(println a …)` | 同 `print`，末尾加换行；返回 `nil` |
- ⚠️ **所有字符串一律加双引号显示**（含 `str` 的产物）；当前实现**没有裸串打印**的方式。数字/布尔/列表/向量等其它值不加引号。

### 7.5 列表（proper list as cons 链）
| 函数 | 语义 |
|------|------|
| `(cons x lst)` | 把 `x` 接到 `lst` 头部；`lst` 可为任意值——接到非列表则形成点对 |
| `(car p)` | 取首元素；`p` 须为非空列表/点对，否则 `car: not a pair` |
| `(cdr p)` | 取首元素之后的其余；`p` 须为非空列表/点对，否则 `cdr: not a pair` |
| `(list …)` | 用参数构造 proper 列表 |
| `(length coll)` | 列表/向量/字符串的**长度**；其他类型报错 |
| `(nth coll i)` | 0 基取第 `i` 个元素；支持列表与向量；越界 `index out of range` |
| `(get coll i)` | 0 基取第 `i` 个元素；支持列表/向量/**字符串**；字符串返回长度 1 的字符串 |

### 7.6 向量
| 函数 | 语义 |
|------|------|
| `[a …]` | 字面量（**求值元素**得新向量；`'[…]` 得不求值数据） |
| `(vec a …)` | 用参数构造向量 |
| `(get v i)` | 0 基取元素；越界报错 |
| `(set v i x)` | **原地**写向量第 `i` 位为 `x`，返回 `x`；**仅向量可用**；越界报错 |
| `(length v)` / `(nth v i)` | 同 §7.5 |

### 7.7 字符串
| 函数 | 语义 |
|------|------|
| `(str a …)` | 把各参数的**裸文本表示**按序拼接成一个**新字符串值**（数字→其文本、字符串→其内容**不带引号**、`nil`→`nil`） |
| `(get s i)` | 取第 `i` 个字符，返回长度 1 的字符串；越界报错 |
| `(length s)` | 字符数 |
- ⚠️ `str` 拼接时**不给参数加引号**，但拼出的仍是字符串**值**；`print`/`println` 打印它时**仍会被加双引号**（见 §7.4）。验证其内容请用 `(length (str …))` 或 `(equal? (str …) \"…\")`。

### 7.8 输入（Input）
| 函数 | 语义 |
|------|------|
| `(input 提示?)` | 从**标准输入**读一行（去掉结尾换行）返回**字符串**；可选的首个字符串参数作**提示**原样输出（不带引号、不换行）后再读 |
| `(input-int 提示?)` | 从标准输入读一行并解析为**十进制整数**返回**数字**；跳过前导空白，空行/非数字返回 `0` |

- **提示**：`input` / `input-int` 都会把可选的首个字符串参数当提示写到 stdout 并立即刷新，然后再读输入。例：`(input-int "你的猜测> ")`。

### 7.9 高阶函数（接受函数作为参数）
| 函数 | 语义 |
|------|------|
| `(map fn coll)` | 对`coll`（列表或向量）每个元素调用 `fn`（单参），按原顺序返回**新列表** |
| `(filter pred coll)` | 只保留 `pred` 返回**真值**的元素，按原顺序返回新列表 |
| `(reduce fn coll)` | 无初值：取首元素为初值，依次 `(fn 累计值 元素)`，返回最终累计值；`coll` 为空 → `nil` |
| `(reduce fn init coll)` | 带初值；等价于 `(reduce fn coll init)`（按「哪个参数是集合」自动判别顺序） |

- `coll` 为**列表或向量**皆可（向量遍历后结果为列表）。
- `fn` 可以是 `lambda` 闭包或任何函数值。
- 例：`(map (lambda (v) (* v v)) [1 2 3])` → `(1 4 9)`；`(reduce + [1 2 3 4])` → `10`。

### 7.10 序列工具
| 函数 | 语义 |
|------|------|
| `(range n)` | `(0 … n-1)` |
| `(range start end)` | `start … end-1` |
| `(range start end step)` | 从 `start` 每次加 `step` 直到 `end`（**不含** `end`）；`step` 为 0 报错 |
| `(last coll)` | 最后一个元素；空集合报错 |
| `(reverse coll)` | 反转，顺序颠倒 |
| `(append a b)` | 顺序拼接（`a` 在前） |
| `(null? x)` | 列表/向量是否为空 |
| `(member? x coll)` | `x` 是否在 `coll` 中（结构相等） |

- `range` 支持负 `step` 做倒序：`(range 5 0 -1)` → `(5 4 3 2 1)`。

### 7.11 关联表
| 函数 | 语义 |
|------|------|
| `(assoc lst key val)` | 在关联表 `lst`（元素形如 `(key value)` 的列表）中，把首个匹配 `key` 的条目替换为 `(key val)`；**无匹配则在表头新增**一条；返回新表（原表不变） |
| `(assoc lst key)` | 两参形式：只查询，返回首个匹配的条目 `(key value)`；**未找到返回 `nil`** |

- 用 `assoc` 从 `'()` 逐条构建关联表：`(assoc (assoc '() 'a 1) 'b 2)`。
- 非法条目（非列表）会被跳过，不会解引用导致崩溃。

### 7.12 类型判断
`(number? x)` `(string? x)` `(list? x)` `(vector? x)` `(function? x)` `(bool? x)` —— 各返回布尔。

### 7.13 数学函数
| 函数 | 语义 |
|------|------|
| `(abs x)` | 绝对值 |
| `(floor x)` / `(ceil x)` | 下取整 / 上取整 |
| `(round x)` | 四舍五入到最近整数 |
| `(sqrt x)` | 平方根；负数报错 |
| `(pow a b)` | `a` 的 `b` 次幂 |
| `(min a …)` / `(max a …)` | 最小 / 最大值；全部参数须为数字 |
- **EOF（输入耗尽，如管道/重定向结束）**：`input` 返回空串 `""`，`input-int` 返回 `0`。
- **`input-int` 解析**：`strtol(…, 10)`，忽略前导空格/制表；`42`、` -7` 正常；`12abc` 取前缀 `12`；纯非数字/空 → `0`。
- **行长上限**：内部缓冲 512 字节，单行超过约 511 字节会被拆成多次读取。
- 这是 Nuomi **首批输入类内置**，用于写交互程序（猜数字、文字冒险等）；脚本模式与 REPL 均可从 stdin 读取。

### 7.14 终端 / 游戏原语（2026-10-21 新增）

实时游戏（贪吃蛇等）需要清屏、帧延时、不阻塞键盘、随机数，这一组就是为它们加的：

| 函数 | 语义 |
|------|------|
| `(cls)` | 清屏 + 光标归位 + **隐藏光标**。适合开局/结束的**一次性**清场 |
| `(home)` | 光标归位 + 隐藏光标，**不清屏**。游戏每帧用这个 |
| `(show-cursor)` | 恢复光标；游戏退出时必须调用，否则光标一直藏着 |
| `(sleep ms)` | 暂停指定毫秒 |
| `(key)` | **非阻塞**读键盘。无按键 → `nil`；方向键 → 符号 `'up`/`'down`/`'left`/`'right`；`Esc` → `'esc`；普通键 → 单字符字符串（如 `"w"`） |
| `(random n)` | `[0, n)` 均匀随机整数；`n <= 0` 返回 `0`。LCG + 时间种子 |
| `(draw s)` | **原样**输出字符串：不加引号（`print` 会加）、不加换行，一次 `fwrite` 写完并 flush |

要点：
- **平台差异**：Windows 走 Win32 控制台 API + conio（`_kbhit`/`_getch`）；其他平台清屏/延时用 ANSI 与 `nanosleep` 兜底，`key` 恒返回 `nil`（无非阻塞键盘）。
- **方向键是两段式**：Windows 控制台方向键是 `0xE0` 前缀 + 扫描码，`key` 已合成成符号返回，脚本侧直接 `(equal? k 'up)` 即可。
- **与 `input` 的分工**：`input` 是行式（等到回车），适合菜单/表单；`key` 是非阻塞（立刻返回），适合游戏主循环。
- **防闪烁三件套**（重要，`samples/snake.nuomi` 实测）：
  1. 每帧**不要** `cls` —— 抹全屏是闪烁根因；用 `home` 只归位，行等宽重绘自然覆盖旧画面；
  2. 整帧拼成**一个**字符串用 `draw` 一次写出 —— 分 22 次写会让控制台呈现半成品画面（撕裂）；
  3. `cls` 只留给出开局/结束的一次性清场。
- **完整示例**：`samples/snake.nuomi`（贪吃蛇，逻辑与渲染分离，逻辑部分可无头单测）。

### 7.15 文件系统（File System）

糯米在 novus 里的定位是**系统壳语言**（≈ Windows 的 PowerShell），文件操作是壳的基本功。
宿主（Windows）用 Win32 API，其他平台用 POSIX；将来跑在 novus 上时这一层换成 novus
文件系统 syscall，**脚本接口不变**。

| 函数 | 语义 |
|------|------|
| `(exists? p)` | 路径存在 → `true` |
| `(is-dir? p)` | 是目录 → `true` |
| `(file-size p)` | 字节数；失败 `-1` |
| `(read-file p)` | 读整个文件 → 字符串（保留字节原样，可含 NUL）；失败 `nil` |
| `(write-file p s)` | 整串覆盖写，自动创建 → 布尔 |
| `(append-file p s)` | 追加到末尾，自动创建 → 布尔 |
| `(ls dir)` | 目录项列表（不含 `.` 与 `..`）；失败/非目录 → `nil` |
| `(mkdir p)` | 建目录 → 布尔 |
| `(rmdir p)` | 删**空**目录 → 布尔 |
| `(delete p)` | 删**文件** → 布尔 |
| `(mv src dst)` | 移动/重命名 → 布尔 |
| `(cp src dst)` | 复制（覆盖目标） → 布尔 |

要点：
- **软错误**：所有失败返回 `nil`/`false`/`-1` 并打印 `Runtime error`，**不中止程序**
  （壳语言要能容忍单个命令失败，与 shell 的 `$?` 同思路）。
- **故意没有递归删除原语**：`rm -rf` 这类破坏性操作用原语在脚本层自己组合——
  `samples/files.nuomi` 里有 6 行实现（`ls` + `delete` + `rmdir` 递归）。
- **`nil` 是空列表**：`map`/`filter`/`reduce` 接受 `nil` 当空集合（0 元素），
  对空目录 `map` 不报错。
- 路径分隔符 `/` 与 `\` 均可（Win32 两者都认；novus 用 `/`）。

### 7.16 JSON

启动器成天跟 JSON 打交道（Mojang 版本清单、版本元数据、Modrinth API、实例配置），故单独成组。

| 函数 | 语义 |
|------|------|
| `(json-parse s)` | 解析 JSON 文本 → 糯米值；失败返回 `nil` + `Runtime error` |
| `(json-get v k...)` | 多层路径取值；对象按键、向量按下标（支持负索引）；找不到返回 `nil` |
| `(json-stringify v)` | 糯米值 → JSON 文本 |
| `(json-obj k v...)` | 构造 JSON 对象 alist，参数须为偶数、键须为字符串 |

**JSON → 糯米值映射**：

| JSON | 糯米 |
|------|------|
| object | alist：`((键 . 值) (键 . 值) ...)` |
| array | 向量 `[a b c]`（`get` 下标 / `length` 长度） |
| string | 字符串（解转义 `\"` `\\` `\/` `\b` `\f` `\n` `\r` `\t` `\uXXXX`，含代理对） |
| number | 数字（double） |
| `true` / `false` | 布尔 |
| `null` | `nil` |

要点：
- **alist 项严格是点对** `("键" . 值)`。曾想也认手写常见的二元表 `("键" 值)`，
  但两种写法在「值恰好是单元素列表」时结构上无法区分——嵌套单键对象
  `{"a":{"b":1}}` 会把内层对象误当成值导致取值串位。**猜不出来就别猜**，
  手写对象请用 `json-obj` 构造器。
- **深度上限 128**：输入常来自网络，防恶意深层嵌套把 C 栈爆掉。
- 软错误：`json-parse` 遇到非法 JSON、尾部残留等返回 `nil`，程序继续。
- 已知取舍：对象取值 **O(n)** 线性扫描（未做字典类型）；`{}` 解析成 `nil`，
  序列化回去是 `null`（空对象与空值不可区分）。

**示例**：`samples/json.nuomi`（从 Mojang 风格清单里刨出启动游戏所需信息）、
`tests/json-test.nuomi`（37 项回归测试）。

### 7.17 HTTP（客户端）

启动器要拉 Mojang 清单、Modrinth API、下载 jar，故加一组 HTTP 原语。
Windows 宿主用 WinINet（运行时动态加载 `wininet.dll`，零链接依赖）；
其他平台暂未实现（将来接 novus 网络 syscall，脚本接口不变）。

| 函数 | 语义 |
|------|------|
| `(http-get url [ua])` | GET，返回响应体字符串；失败 `nil` |
| `(http-head url [ua])` | HEAD，返回状态码；拿不到返回 `-1` |
| `(http-length url [ua])` | 取 `Content-Length`；拿不到 `-1` |
| `(http-download url dest [ua])` | GET 并落盘，返回写入字节数 |
| `(http-download-from url dest offset [ua])` | **断点续传**：带 `Range: bytes=offset-` |

要点：
- **软错误**：失败返回 `nil`/`-1` 并打印 `Runtime error`，不中止程序。
- **双通道**（本机代理环境下的实测结论）：
  · 简单 API（`InternetOpenUrlA`）—— 皮实，HTTPS 走代理也通，但拿不到状态码；
  · 高级 API（`HttpOpenRequest`）—— 有状态码/HEAD，但本机 TLS + 代理会挂。
  默认按环境变量 `NUOMI_HTTP_MODE=advanced|simple` 选择，未设则用简单通道。
- **续传的追加/覆盖判定**：简单通道拿不到 206，改用**内容自校验** ——
  请求头是 `Range: bytes=<offset>-`，服务器只有两种行为：
  遵守 Range → 返回剩余部分（开头与已下载文件的开头不同）；
  忽略 Range → 返回整份（开头相同）。据此决定追加还是覆盖。
- Range 请求必须同时带 `Accept-Encoding: identity`，否则服务器回 gzip 压缩流，
  而带 Range 的响应 WinINet 不自动解压，追加到未压缩文件上就是乱码。

**示例**：`samples/http.nuomi`（拉 Mojang 清单 → 选版本 → 读元数据 →
Maven 坐标转 jar 路径 → 断点续传 → 生成实例配置，全流程真网络）。

## 8. 错误与诊断语义（重要）

- **运行时错误是非致命的**：底层机制是向 `stderr` 打印 `Runtime error: <消息>`，随后**出错表达式求值为 `nil`**，程序**继续执行**（无异常/栈展开）。
  - 例：未绑定变量、`arity mismatch`、`car: not a pair`、除零等均为软错误。
- **解析错误会中止读入**：读取器遇括号不配对、未闭合字符串等会报错并停止继续解析后续形式。
- 因此顶层脚本的"运行结果"是最后一个成功求值形式的返回值；中途软错误不改变控制流，只是局部返回 `nil`。

---

## 9. 函数与调用

- **定义**：`(define (f p…) body…)` 或 `(define f (lambda (p…) body…))`。
- **调用**：`(f a…)`，实参**从左到右**求值后按位绑定到形参。
- **Arity**：**实参个数必须严格等于形参个数**，否则 `arity mismatch`（当前**不支持可变参数/缺省参数**）。
- **作用域**：**词法作用域 + 闭包**。`lambda`/`define` 捕获"定义时的环境"；调用时新建以其捕获环境为父的子环境绑定实参。`if/while/begin/and/or` 的表达式在**当前环境**求值（不引入新作用域）。
- **递归**：函数可直接引用自身（定义时名字已进入所在环境）；`factorial`、`fibonacci` 等可直接递归。
- **高阶函数**：闭包为一等公民，可作参数/返回值。

---

## 10. 数值模型

- 全部数值为 IEEE-754 双精度 `double`。
- 除零 → 运行时错误；取模用 `fmod`。
- **显示**：整数取值按十进制整数打印（无 `.0`）；非整数按 `%g`（6 位有效数字，超大/超小用科学计数法）。**注意显示精度仅为 6 位**，与内部 53 位尾数不同（诊断输出用；程序内计算不受该格式化影响）。
- 大整数超出 `2^53` 精确范围会丢精度（无 BigInt）。

---

## 11. 保留字（Reserved Words）

以下符号被特殊形式占用，**不可**作为可调用函数名/变量名正常使用（列表首元素命中即优先分派为特殊形式）：
```
quote  if  while  define  set!  lambda  begin  and  or
```

## 12. 最小完整示例

```nuomi
; fib.nuomi
(define (fib n)
  (if (< n 2)
      n
      (+ (fib (- n 1)) (fib (- n 2)))))
(println (fib 10))          ; 输出 55

; counter.nuomi —— 闭包 + set! 计数器
(define (make-counter)
  (define n 0)
  (lambda () (set! n (+ n 1)) n))
(define c (make-counter))
(println (c) (c) (c))               ; 1 2 3

; vectors.nuomi —— 向量字面量 / get / set / 相等性
(define v [10 20 30])
(println (get v 0))                 ; 10
(set v 1 99)
(println v)                         ; [10 99 30]
(println (equal? [1 2] [1 2]))      ; true
(println (eq? v v))                 ; true

; strings.nuomi —— str 拼接（内容裸） vs println 显示（给字符串加引号）
(println (equal? (str "Hi, " "Nuomi") "Hi, Nuomi"))  ; true（str 拼出内容 "Hi, Nuomi"）
(println "Hi")                                        ; "Hi"（println 给字符串加引号）
```

> 说明：`println` 顶层会把字符串加引号显示（`"…"`）；纯数字/列表不加。例 `(println "fib(10) =" (fib 10))` 实际输出为 `"fib(10) =" 55`。

## 13. 已知限制（Current Limitations）

1. **数值仅 `double`**：无整数/浮点/大整数区分。
2. **引用计数不回收环**：相互引用的闭包/环境在运行期不释放，程序退出时由 `freeAllObjects()` 统一回收；不构成运行期泄漏，但长时不回收。
3. **无可变参数与缺省参数**：函数 arity 须严格匹配。
4. **无宏 / 模块 / 异常处理 / 尾调用优化**。
5. **`set!` 需已存在绑定**：无隐式全局变量；闭包对外层绑定的写入遵循所在环境槽位。
6. **字符串转义子集**：仅 `\n \t \" \\`（见 §2.6）。
7. **显示精度** `%g` 6 位有效数字（仅影响输出，不影响内部计算）。
8. **特殊形式名字保留**（见 §11）。
9. **无 `random` / `time` / 文件·网络 等内置**：需要随机数/当前时间须自行实现（如样例内置的 LCG 伪随机）；⚠️ 数值为 `double`，LCG 的 `乘子×态` 若超 2^53 会丢精度（选小乘子如 9301 可保精确）。要键盘交互输入请用 §7.8 的 `input` / `input-int`。

## 14. 与 novus-os / NUC 的关系

本规范描述**宿主解释器**（在 Linux/macOS/Windows 上读源码运行）的语言语义。Nuomi 的目标产物是 novus-os 的 `.nuc` 原生可执行：

- **运行**：`nuomi 文件.nuomi` 执行脚本；无参进入 REPL。
- **编译（Route-A M2）**：`nuomi -c 文件.nuomi -o 输出.nuc` 支持 **整数运算 + 函数(可递归) + 局部变量 + if/while/begin + 比较** 的 x86_64 原生码（System V 调用约定；跨函数调用经 `R_X86_64_PC32` 重定位 + FUNC 符号表 §5/§7，由加载器装载期解析）。限制：无 字符串/向量/内置 I/O（novus 系统调用号表公布后以 `(syscall n ...)` 接入）；编译期布尔为 1/0；顶层 `define` 为编译期常量（不可 `set!`）；每函数 ≤6 参数、≤32 个局部槽。
- NUC 工具链（`nuomi nuc`：`emit-demo` / `validate` / `dump` / `run`）跨 Windows/Linux/macOS，已并入 `nuomi.exe` 单一文件。

> 环境对齐示例（Linux + gcc）：
> ```bash
> make            # 生成单一 ./nuomi（已含 NUC 工具链）
> make test       # 冒烟：跑全部样例 + nuomi nuc emit-demo/validate/run
> ```
